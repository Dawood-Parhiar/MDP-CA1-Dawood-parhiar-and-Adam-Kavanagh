To make this game a networked multiplayer game, I will use TCP (Transmission Control Protocol). A new State called multiplayer state will be preferred here instead of game state. multiplayer state will hold our Players lets say 15 or 30 max. we will draw our World that we have built, as this state will be extending from State class so we will handle input of our players and update by frames. The game will have a client-server based structure where server will know the realtime inputs and events requests(Packets) coming from the clients (players in our case). I would create a lobby system to support this game's multiplayer functionality, where player's would join a lobby and make themselves ready. if all ready or min players ready then the server will get a message to start the game and players get countdown of 5 saying game starts in 5 seconds. I would make the world a bit wider and longer to deal with the amount of players mentioned above e.g 16. the enemies NPCs available in the current version of the game may be taken out so the game will be players against players.
